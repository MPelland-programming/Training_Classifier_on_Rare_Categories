# Training a Classifier on Rare Categories

Can LLM-generated text stand in for scarce, human-labeled data when training a transformer classifier? This project compares transformer text classifiers trained on **real (human-written) data** against classifiers trained on **synthetic data generated by Claude**, evaluated on held-out real data.

## Overview

Labeled examples are often hard to come by for rare categories. Here, Claude is prompted to write new examples for each category, and the resulting classifiers are compared with ones trained on a small sample of real examples. The experiments vary:

- **Training data source:** real data vs. Claude Haiku 4.5-generated vs. Claude Sonnet 4.5-generated
- **Architecture:** DistilBERT vs. RoBERTa
- **Fine-tuning scope:** all weights vs. classification head only
- **Training set size:** number of real samples per class

## Data

**Real data:** the [Yahoo Answers classification dataset](https://www.kaggle.com/datasets/bhavikardeshna/yahoo-email-classification) from Kaggle (answer text, 10 topic labels). Five topics are used:

| Label | Topic |
|-------|-------|
| 1 | Society and Culture |
| 2 | Science and Mathematics |
| 4 | Education and Reference |
| 8 | Entertainment and Music |
| 9 | Family and Relationships |

Real training sets are small (1,000 samples per class by default), with stratified validation and test splits drawn from the rest of the data.

**Synthetic data:** generated with the Anthropic Message Batches API (`claude_generation.py` and the notebook):

- For each topic, the prompt is given 15 real example answers as cached context (prompt caching).
- Claude is asked to write a new Yahoo! Answers-style answer on the topic, without the question or any preamble.
- A target length for each answer is sampled from the empirical token-length distribution of the real data, so synthetic and real texts have similar lengths.
- 250 answers per request batch, repeated 4 times, gives 1,000 synthetic answers per topic.
- **Haiku 4.5** generated data for all five topics; **Sonnet 4.5** generated data for topics 1 and 2.

## Models and training

- **Architectures:** `distilbert-base-uncased` and `roberta-base` (Hugging Face Transformers), with max sequence length 512.
- **Settings:** batch size 32, 2 epochs (pre-tests showed overfitting by epoch 2). Learning rate 2e-4 for DistilBERT, 2e-5 for RoBERTa.
- **Fine-tuning modes:** all weights, or head only (encoder frozen, classifier trainable).
- **Tasks:** a 5-class problem (Haiku vs. real data) and a 2-class problem on topics 1 and 2 (Sonnet vs. real data).
- **Metrics:** accuracy and confusion matrix (via `evaluate`) on held-out real test data.

## Getting started

1. Open `DLProject.ipynb` in Google Colab (it can also run locally with `train.tsv` in place).
2. Add your `ANTHROPIC_API_KEY` as a Colab secret (or environment variable) if you want to regenerate synthetic data. Set `gen_text = True` in the generation cell.
3. Set the experiment parameters in the "Parameter choice" cell (`archi`, `sample_sizes`, `head`, `model2train`, etc.).
4. Run the notebook top to bottom.

**Dependencies:** `torch`, `transformers`, `datasets`, `evaluate`, `anthropic`, `scikit-learn`, `pandas`, `numpy`, `matplotlib`, `seaborn`, `kagglehub`. A GPU is recommended.
